Why Was the Big Data Stack Essential?

🐘

Hadoop HDFS vs Local Filesystem

Local filesystems lock compute to a single physical disk, causing severe I/O thrashing during parallel partition reads. HDFS divides datasets into 128 MB blocks across cluster nodes. Spark leverages data locality to schedule execution directly where data resides, avoiding costly network transfers.

⚡

Apache Spark vs Single-Node Pandas

Pandas loads entire datasets into uncompressed memory, consistently throwing Out-Of-Memory (OOM) errors during rolling window joins across 8.9 GB raw time-series. Spark builds an optimized in-memory execution DAG with lazy evaluation and distributed spill-to-disk caching.

🌲

Spark MLlib vs Scikit-Learn

Scikit-learn requires all training matrices in single-machine RAM and executes tree building in a single process. Spark MLlib parallelizes candidate node splitting across worker executors via DTStatsAggregator, training 100 deep trees on 518k samples in minutes.

🐝

Apache Hive vs Traditional MySQL

Traditional SQL databases require slow ETL duplication into proprietary B-tree tables. Hive implements schema-on-read directly over existing HDFS Parquet files, decoupling compute from storage and enabling interactive analytical auditing across 33 model runs.
