Architectural Tool Justifications (Course Requirements Matrix)

Technical justifications for why standard single-node tools (Pandas/Scikit-Learn/Postgres) were rejected in favor of the Apache Big Data Stack.

Component Selected Big Data Tool Rejected Alternative Technical & Architectural Justification
Distributed Storage Apache Hadoop HDFS Local POSIX Filesystem / NFS Provides block-level (128 MB) fault tolerance and rack awareness across commodity nodes. Crucially, allows Spark to schedule compute on the exact physical worker hosting data blocks (PROCESS_LOCAL), avoiding expensive network shuffles across 837k rows.
In-Memory Processing Apache Spark 3.5 (PySpark) Pandas / Python Multiprocessing Single-node Pandas crashes with Out-Of-Memory (OOM) during rolling window joins across 8.9 GB raw time-series. Spark constructs an optimized in-memory DAG (Directed Acyclic Graph) with lazy execution, distributed caching, and zero memory thrashing.
Distributed ML Engine Spark MLlib RandomForest Scikit-learn RandomForestClassifier Scikit-learn requires all training data to fit in single-machine RAM and trains trees sequentially. Spark MLlib distributes tree node splitting across worker cores using DTStatsAggregator, training 100 deep trees on 518k samples in minutes.
Data Warehouse / Catalog Apache Hive 4.0 Metastore Traditional Relational RDBMS (MySQL) Provides schema-on-read directly over the existing HDFS Parquet warehouse without copying or duplicating data. Decouples compute from storage, enabling Spark SQL, Hive CLI, and external audit scripts to query model experiments simultaneously.
Storage Format Apache Parquet (Snappy) CSV / TSV Flat Files Columnar layout enables projection pruning (reading only requested features from disk) and predicate pushdown. Snappy block compression reduced raw 8.9 GB TSV footprint by over 75% down to ~2.1 GB while maintaining high-speed CPU decompression.

SELECT experiment_id, feature_set, round(decision_threshold, 4) AS thresh, 
       round(tss, 4) AS tss, round(tpr * 100, 2) AS recall_pct, round(fpr * 100, 2) AS fpr_pct, 
       round(precision * 100, 2) AS prec_pct, round(f1_score, 4) AS f1, tp, fp, tn, fn
FROM solar_flare.model_experiments 
ORDER BY tss DESC;
