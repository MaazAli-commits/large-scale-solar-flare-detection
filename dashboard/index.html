Architectural Tool Justifications (Why the Big Data Stack was Essential)

🐘

Hadoop HDFS vs Local Filesystem

Block-Level Distribution & Fault Tolerance

Local filesystems lock compute to a single disk. HDFS fragments files into 128 MB blocks across cluster nodes. Crucially, Spark leverages data locality to schedule execution on the physical node hosting the block, avoiding costly network transfer of 837k time-series rows.

⚡

Apache Spark vs Pandas

In-Memory Directed Acyclic Graph (DAG)

Single-node Pandas crashes with Out-Of-Memory (OOM) during rolling window joins across 8.9 GB raw time-series. Spark constructs an optimized in-memory execution DAG with lazy evaluation and distributed caching, scaling effortlessly across all CPU cores.

🌲

Spark MLlib vs Scikit-Learn

Distributed Tree Induction via DTStatsAggregator

Scikit-learn requires all training data to fit in single-machine RAM and constructs trees sequentially. Spark MLlib distributes tree node splitting across worker executors using DTStatsAggregator, training 100 deep trees on 518k samples in minutes.

🐝

Apache Hive vs Traditional MySQL

Schema-on-Read over Data Warehouse

Traditional RDBMS requires duplicating data into proprietary tables. Apache Hive creates a virtual SQL metastore directly over the existing HDFS Parquet files. Decouples compute from storage, allowing Spark SQL and audit scripts to query model experiments simultaneously.

🐝

       round(precision * 100, 2) AS precision_pct, round(f1_score, 4) AS f1_score, tp, fp, fn
FROM solar_flare.model_experiments 
ORDER BY tss DESC;
